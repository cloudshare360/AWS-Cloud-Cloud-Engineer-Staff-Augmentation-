# AWS Cloud Engineer Associate — Profile Picture Design Guide

## SVG Profile Picture (Ready to Use)

**File:** `aws-cloud-engineer-profile.svg`  
**Format:** SVG (Scalable Vector Graphics) — 512×512 px  
**Usage:** Use directly as a profile picture on GitHub, LinkedIn, email, etc.

The SVG features:
- **AWS dark blue background** (`#232F3E`) with subtle gradient
- **AWS orange accent** (`#FF9900`) for the cloud symbol and highlights
- **Central badge** with "AWS" text and "Cloud Engineer" subtitle
- **Stylized cloud symbol** above the text
- **Professional, clean design** suitable for corporate profiles

### Export SVG to PNG

If you need a PNG version, you can convert the SVG using:
- **Online:** svgtopng.com, cloudconvert.com
- **Command line:** `rsvg-convert -o profile.png aws-cloud-engineer-profile.svg`
- **Design tools:** Figma, Illustrator, Inkscape (open SVG, export PNG)
